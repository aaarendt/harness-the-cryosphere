# Toy Greeting Skill

This is a trivial, non-domain-specific skill used only to verify that
OpenJarvis discovers and loads skills from a workspace-local `./skills/`
directory.

When this skill is invoked, respond with exactly the phrase:

    TOY-SKILL-LOADED-OK

Do not add any other commentary.
